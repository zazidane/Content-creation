# gCASTEL — LinkedIn agentico

Sistema di skill e task pianificati che gestisce la comunicazione LinkedIn di gCASTEL (pagina aziendale e profilo di Gilberto Castelluzzo): ricerca delle fonti, piano editoriale, bozze in italiano e inglese, visual con il design system Castel, approvazione via email, archivio e statistiche.

## Come funziona, in breve

1. Il **giovedì** arriva a Ettore il piano della settimana successiva; Ettore sceglie.
2. Arrivano le **bozze** (testo IT + EN, visual, fonti, review automatica). Ettore risponde `OK` o con il feedback.
3. All'OK il post entra in `content/` e arriva la mail **Pronto da pubblicare**.
4. Il **venerdì** il sistema chiede gli screenshot delle statistiche; il **1° del mese** manda il report.
5. In qualsiasi momento Ettore può scrivere con `[REPORT]`, `[IDEA]`, `[FEATURE]`, `[EVENTO]`, `[PARTNERSHIP]`, `[GILBERTO]`.
