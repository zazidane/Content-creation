# Analytics

- `metrics.csv` — una riga per post per rilevazione (dagli screenshot che Ettore invia il venerdì).
- `page.csv` — numeri della pagina (follower, visite).
- `weekly/<anno>-W<ss>.md` — riepilogo settimanale.
- `monthly/<anno>-<mm>.md` — report mensile approvato.

Engagement rate = (reazioni + commenti + repost + clic) / impression.
